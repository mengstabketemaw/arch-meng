# Telescope Search

## Find & Grep

| Key Combination | Action |
|---|---|
| `Space s f` | Find files. |
| `Space S F` | Find files, including gitignored and hidden. |
| `Space s g` | Live grep across the project. |
| `Space S G` | Live grep, including gitignored and hidden. |
| `Space s w` | Grep the word under the cursor (or the selection). |
| `Space s /` | Live grep only in open files. |
| `Space /` | Fuzzy search in the current buffer. |
| `Space Space` | Switch between open buffers. |
| `Space s .` | Recently opened files. |
| `Space s r` | Resume the last Telescope search. |
| `Space s d` | Diagnostics. |
| `Space s k` | Keymaps. |
| `Space s h` | Help tags. |
| `Space s c` | Commands. |
| `Space s n` | Neovim config files. |
| `Space s s` | List all Telescope pickers. |
| `gO` | Document symbols (LSP). |
| `gW` | Workspace symbols (LSP). |
| `grr` | References (LSP). |
